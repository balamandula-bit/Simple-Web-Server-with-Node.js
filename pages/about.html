About this project

This server was built as part of a Node.js fundamentals assignment. The goal was to understand how basic web servers handle requests and responses.

Every request is handled manually: reading the URL, matching a route, reading the HTML file from disk asynchronously, and writing the response with the correct status code and content type.

The CSS file is also served through the same server.
