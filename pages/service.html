NodeServe Home About Contact Services

Server features

These are the main parts included in this assignment.

01

Multiple routes

Routes for /home, /about, /contact, /services, and a fallback 404 are all resolved through a single request handler.

02

Async file reads

HTML files are read with fs.promises.readFile, so the file loading is asynchronous.

03

CSS serving

The server handles /style.css and sends it with the correct content type.

04

Custom 404 page

Unknown routes get a styled 404 page instead of a raw error.

05

Root redirect

Visiting / automatically redirects to /home with a 301 status code.

06

500 error handling

If a file read fails unexpectedly, the server catches the error and returns a 500 response gracefully.
